# 컴포넌트 (1라운드, 2026-11-29)

값은 `tokens.md` 이름을 쓴다. 목업 소스는 `src/app.css`(클래스 이름을 괄호에 적음). 캡처는 `screens/`.

## 1. 캐릭터 자리표시 `CharacterPlaceholder` (.ph)

그래픽 디자이너가 캐릭터를 확정하기 전까지 모든 화면에서 이 칸을 쓴다. 캐릭터가 바뀌어도 칸 크기·무대·안내선은 그대로라 화면 디자인은 바꿀 필요가 없다.

- 검정 무대 위 정사각. 크기: 36(축소 아일랜드), 80(확장·잠금), 96(중 위젯), 116~132(앱 미리보기), 칸 안(118 칸에서 안쪽 14 여백).
- 점선 두 줄: 108px 캔버스 기준 그림 안전 구역 y 17~91(그래픽 디자이너 3라운드 규칙). 실제 그림이 들어가면 점선과 회색 덩어리는 지운다.
- 왼쪽 아래 작은 꼬리표: "햄스터 · 80pt 자리". 개발 빌드에서만 보이게.

## 2. 캐릭터 칸 `CharacterTile` (.cell)

118×118 정사각(402pt 폭, 3열, 가로 간격 8) + 아래 이름(subheadline semibold) + 상태(caption). 글자는 왼쪽 정렬.

| 상태 | 테두리 | 그림 | 오른쪽 위 배지 | 상태 글자 | VoiceOver |
|---|---|---|---|---|---|
| 기본(고를 수 있음) | 0.5pt stage-edge(다크만) | 100% | 없음 | "무료" text-2 | "펭귄, 버튼" |
| 선택(사용 중) | 2pt accent 실선 | 100% | 22pt 주황 원 + 검정 체크 | "사용 중" accent-text | "햄스터, 선택됨" (`.isSelected`) |
| 잠김(구매 전) | 0.5pt | 45% 불투명 | 22pt 회색 원(#2A2A2A) + 자물쇠(#D6D2CA) | "팩에 포함" text-2 | "토끼, 동물 팩, 잠김. 두 번 탭하면 미리보기" |
| 미리보기 중 | 1pt accent 점선 | 100% | 자물쇠 유지 | 작은 막대 3개 + "미리보는 중" accent-text | "강아지, 미리보는 중" |
| 눌림 | — | 96% 크기(0.12초) | — | — | — |

동작
- 무료 칸 탭: 바로 선택(체크 이동) + 위 미리보기 무대가 그 캐릭터로 바뀜 + 아일랜드에 즉시 반영(`startOrUpdate`). 햅틱 `.selection`.
- 잠긴 칸 탭: 선택은 바뀌지 않고 미리보기만. 무대에 "미리보기 · 동물 팩"과 [동물 팩 보기] 주 버튼.
- 잠긴 칸 길게 누르기: 컨텍스트 메뉴 없음(MVP). 탭과 같다.
- 선택은 한 번에 하나. 칸 묶음 전체가 라디오 그룹.

## 3. 미리보기 무대 `PreviewStage`

- 검정 무대, 좌: 캐릭터 116, 우: 이름(title2) / 상태 한 줄(foot, 미리보기면 accent) / 속도 세그먼트 / 버튼.
- 속도 세그먼트 `SpeedPicker`: 쉼·보통·빠름 3칸, 높이 32(칸 바깥 여백 포함 터치 44). 기본값은 지금 CPU 단계. 바꾸면 미리보기 속도만 바뀐다(아일랜드에는 영향 없음).
- 아래 줄 "아일랜드에서는 [36pt 알약]": 고른 캐릭터가 축소 아일랜드에서 어떻게 보일지 실제 크기로 보인다.
- 버튼: 무료·선택 안 됨 → [이 캐릭터로] 주 버튼 / 이미 선택됨 → 버튼 없음, 상태 줄 "사용 중" / 잠김 → [동물 팩 보기].

## 4. 버튼 `IRButton`

| 종류 | 모양 | 글자 | 쓰는 곳 |
|---|---|---|---|
| 주(primary) | 캡슐, accent 채움 | 검정 headline | 화면당 하나: [동물 팩 보기], [아일랜드에서 시작] |
| 보조(bordered) | 캡슐, surface-2 | text-1 | [중지] |
| 꺼짐(disabled) | 캡슐, surface-2 | text-2 | [구매는 다음 업데이트부터] |
| 글자(text) | 바탕 없음 | accent-text | [구매 복원], 가격 링크 |

- 높이 최소 44, 작은 버튼(sm)은 보이는 높이 34에 터치 영역을 44로 넓힌다(`.contentShape` + padding).
- 화면 너비를 꽉 채우는 버튼은 시트의 구매 버튼 하나뿐.

## 5. 속도 단계 자 `TierRuler`

- 4칸 비율 10:40:30:20 = CPU 0~9 쉼 / 10~49 보통 / 50~79 빠름 / 80~100 최고(제안값, 개발자와 확정).
- 지금 칸만 주황 채움 + 검정 글자. 2pt 세로 표시선이 실제 값 위치.
- 아일랜드·잠금 화면에서는 글자 없이 높이 4 띠로 줄여 쓴다.

## 6. 지표 띠 `MetricStrip` / 지표 칸 `MetricCell`

- 카드가 아니라 0.5pt 세로선으로 나눈 3칸 한 줄(CPU, 메모리, 배터리).
- 칸: 머리(caption2, 자간) → 숫자(readout-s, 단위는 footnote text-2) → 3pt 막대.
- 값이 바뀌면 숫자는 `.contentTransition(.numericText())`, 막대는 0.3초 easeOut.
- 배터리 20% 이하면 숫자와 막대 bat-low. 충전 중이면 숫자 옆 번개(`bolt.fill`) 12pt.

## 7. 실시간 그래프 `CPUSparkline`

- 최근 60초, 1초 1점. 높이 44, 가는 선 1.5pt accent, 가로 눈금 25/50/75%.
- 축 글자 "60초 전" "지금" caption2. Swift Charts `LineMark` 로 충분.
- VoiceOver: 그래프 하나로 읽음, "최근 1분 CPU, 최저 18%, 최고 55%, 지금 42%".

## 8. 아일랜드 상태 줄 `LiveActivityRow`

- surface 묶음 안 한 행: 점(주황=달리는 중, text-3=꺼짐) / 제목 / 설명 / 오른쪽 버튼.
- 상태
  - 꺼짐: "꺼져 있음" + [아일랜드에서 시작] 주 버튼
  - 달리는 중: "달리는 중 · 잠금 화면에도 보임 · 5시간 48분 남음" + [중지] 보조 버튼
  - 30분 이하 남음: 남은 시간 accent-text
  - 시스템이 끝냄: "8시간이 지나 꺼졌습니다" + [다시 시작] 주 버튼
  - 사용자가 Live Activity 를 꺼 둠(설정 앱): "iPhone 설정에서 실시간 현황이 꺼져 있습니다" + [설정 열기] 글자 버튼

## 9. 탭 막대 `RootTabView`

- 탭 3개: 러너(`gauge.with.needle`), 캐릭터(`square.grid.2x2`), 설정(`gearshape`). 시스템 `TabView` 그대로(iOS 26 떠 있는 막대). 선택 색 accent-text.
- 목업의 아이콘은 SF Symbols 를 흉내 낸 임시 선 그림이다. 실제 앱은 이름으로 SF Symbols 를 쓴다.

## 10. 팩 시트 `PackSheet`

- `.sheet` + `.presentationDetents([.medium, .large])`, 그래버 보임.
- 제목(title2) + "6종 · 한 번 사면 계속 사용" / 닫기(44 원, `xmark`) / 6칸 한 줄 자리표시 / 사실 3줄(쓰는 곳, 동작, 가족 공유) / 구매 버튼.
- MVP: 구매 버튼은 꺼짐 상태와 안내 한 줄. StoreKit 붙인 뒤: [1,100원] 주 버튼, 구매 중 진행 표시, 실패 시 시트 안 한 줄 오류, 성공 시 시트 닫고 칸 자물쇠가 사라지며 햅틱 `.success`.

## 11. 설정 행

시스템 `Form` + `Section(header:footer:)` 그대로. 고르기 행은 오른쪽 체크(`checkmark`, accent-text), 바깥 링크는 `arrow.up.right`, 안쪽 이동은 `chevron.right`.
