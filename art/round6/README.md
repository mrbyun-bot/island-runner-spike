## 스타일 규칙
- 몸은 한 덩어리 단색 면. 윤곽선·음영·그라데이션·반짝이 없음.
- 색은 캐릭터당 3색(몸색, 배색, 포인트) + 공통 눈 먹색 `#231C1A` 하나.
- 배색은 동물의 먼 쪽 다리·귀, 사물의 기관실·바퀴 무늬에 써서 앞뒤를 나눈다(선 대신).
- 눈은 점 하나(옆모습). 지름 6px@3x = 36px 에서 2px. 쉼에서는 짧은 가로선(감은 눈).
- 모두 오른쪽을 보는 옆모습. 큰 머리, 짧은 다리. 바닥선 y=90, 핵심은 y 15~93 안.
- 달리기 4장은 네 다리를 90도씩 어긋나게 움직여 4장이 전부 다르게. 몸 흔들림 0~2px. 쉼 2장은 세로 4.5% 숨쉬기.

## 11종 판정 (36px 실제 크기 기준)
| | 판정 | 이유 | 프레임차 최소 |
|---|---|---|---|
| 강아지 | ○ | 처진 귀와 주둥이 | 26% |
| 토끼 | ○ | 긴 귀 | 19% |
| 거북이 | ○ | 등껍질 반원. 가장 안정적 | 16% |
| 오리 | ○ | 주황 부리, 뾰족 꼬리 | 20% |
| 다람쥐 | ○ | 몸만 한 꼬리 | 30% |
| 판다 | △ | 눈 무늬가 회색 점 하나로 뭉쳐 흰 양·흰 개로도 보임 | 30% |
| 기차 | ○ | 굴뚝, 바퀴 3개, 연결봉 | 18% |
| 자전거 | ○ | 바퀴 두 개와 삼각 틀. 얼굴은 넣지 않음 | 34% |
| 스케이트보드 | △ | 납작해서 위아래 잘린 칸 안에서 작다. 눈 점은 36px 에서 거의 안 보임 | 50% |
| 열기구 | ○ | 모양은 확실. 바구니 흔들림이 작아 "달린다" 느낌은 약함 | 17% |
| 로켓 | ○ | 불꽃 길이 변화가 잘 보임 | 17% |

36px 에서 안 읽히는 것(×)은 없습니다. 판다는 귀를 더 키우고 눈 무늬를 키우는 쪽, 스케이트보드는 위에 작은 것을 태우는 쪽(태우면 단순함이 깨져 이번엔 안 함)이 다음 손볼 곳입니다. 거북이·열기구·로켓은 프레임 차이가 16~17%로 기준(15%)을 겨우 넘습니다.

## 닮음 자체 점검
- 고양이는 그리지 않음(RunCat). 단색 실루엣만 있는 RunCat 방식과 달리 몸색·배색·점 눈이 있는 색면 그림.
- Pixel Pals 처럼 도트(픽셀 격자)로 그리지 않음. 벡터에서 바로 36px 로 내보냄.
- 먼작귀: 흰 몸 + 갈색 선, 노란 토끼, 크게 벌린 입 없음. 토끼는 흰 몸이지만 선 없고 분홍 귀 안쪽만.
- 뽀로로(파란 펭귄·고글), 햄타로(주황·흰 햄스터) 없음. 다람쥐는 주황이지만 햄스터처럼 둥근 볼 없이 뾰족 귀 + 큰 꼬리.
- 기차는 얼굴을 앞면이 아니라 보일러 옆에 점 하나(토마스와 다름).
- 확인 방법은 기억 기준 비교입니다. 원본 그림을 나란히 놓고 비교하지는 않았습니다.
